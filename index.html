about me

I think like an attacker, to defend like a pro.

I'm an offensive security researcher at AQSEC in Lahore, where I run internal network penetration tests and red team engagements across Active Directory, web, network and API environments. As an independent researcher on HackerOne, I've had vulnerabilities validated and rewarded at RISCO Group, LoginRadius, Nordantech (€500 bounty), goBluebird and signageOS.

My approach: manual, hypothesis-driven testing mapped to the OWASP Top 10, the OWASP Web Security Testing Guide and MITRE ATT&CK. Scanners are a starting point, not the deliverable. Every finding comes with reproduction steps, business impact and a fix your engineers can actually ship.

I take on freelance security assessments for startups and businesses: web apps, APIs, internal networks and AI agents. I only test systems you own or are authorized to test, under a written scope.

what I offer

Security Testing Services

Manual testing, not scanner output. Every engagement ends with a report your developers can act on and a retest once fixes ship.

01
Web Application Penetration Testing

OWASP Top 10 and WSTG coverage: broken access control, IDOR, SQL injection, XSS, SSRF, authentication, session handling and business logic flaws.

02
API Security Testing

REST and GraphQL APIs tested for authorization flaws (BOLA/IDOR), authentication weaknesses and sensitive data exposure.

03
Internal Network & Active Directory

Assumed-breach testing across Windows and Linux, AD misconfigurations and attack paths to Domain Admin, mapped to MITRE ATT&CK.

04
AI Agent & LLM Security

Prompt injection, unsafe tool use, insecure output handling and data leakage in chatbots and AI agents with real credentials.

05
Vulnerability Assessment & Compliance Mapping

Findings prioritized by business impact and mapped to NIST CSF, ISO 27001 or CIS Controls for audit-driven teams.

06
Reporting & Retesting

Reproduction steps with HTTP evidence, CVSS v3.1 severity, CWE mapping, an executive summary, and fix validation after you patch.
